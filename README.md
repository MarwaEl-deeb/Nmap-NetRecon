# Nmap Commander Pro

A modern GUI-based Nmap automation tool made with CustomTkinter.

## Features
- Target Specification
- Scan Techniques
- Host Discovery
- Port Specification
- Service/Version Detection
- Timing & Performance
- NSE Scripts
- Firewall/IDS Evasion
- Output Export (txt / pdf)

## Install
### Nmap
https://nmap.org/download#windows

### Requirments 
pip install -r requirements.txt


## Run
python main.py
